# Runtime Tasks Directory

This directory stores ephemeral task files generated by the **Manager Agent** for execution by **Worker Agents**.

## Lifecycle of a Task File
1. **Creation:** Manager creates `task-<id>.md` using [`templates/task.md`](file:///home/ishaan/Work/ai-chief/templates/task.md).
2. **Execution:** Worker reads `task-<id>.md`, performs the work, and outputs [`templates/worker_report.md`](file:///home/ishaan/Work/ai-chief/templates/worker_report.md).
3. **Ingestion & Archival:** Manager ingests the report, updates persistent memory in `memory/`, and marks the task complete.
4. **Cleanup:** Cleaner Agent or Manager removes or archives old task files in this folder to keep the workspace clean.
